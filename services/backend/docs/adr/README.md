# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records documenting significant architectural decisions made during the development of the Orchid backend services.

## ADR Index

| ADR | Title | Status |
|-----|-------|--------|
| [ADR-0001](adr-0001-agent-flow-audit.md) | Agent Flow Audit | Accepted |

## ADR Template

When creating a new ADR, use the following structure:

```markdown
# ADR-XXXX: Title

**Status:** Proposed | Accepted | Deprecated | Superseded
**Date:** YYYY-MM-DD
**Authors:** Name(s)

---

## Context
[Describe the context and problem]

## Decision
[Describe the decision and its details]

## Consequences
[Describe positive and negative consequences]

## Related ADRs
[Link to related decisions]

## References
[Links to relevant code and documentation]
```
