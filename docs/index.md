## Project Summary

**Orchid Core** is the backend API for an ecosystem of applications, built with:

- **.NET 9** with Hexagonal Architecture
- **PostgreSQL 17** + pgvector for vector search
- **Redis** for caching and sessions
- **RabbitMQ** for async messaging
- **Semantic Kernel** for AI/LLM orchestration
- **Langfuse** for LLM telemetry

### Key Features
- AI Agent Management with Plugin Marketplace
- Real-time Chat with RAG capabilities
- Knowledge Base with vector embeddings
- Spreadsheet processing with NL queries
- Team collaboration and video calls
- Credit-based subscription system
- JWT + OAuth authentication
